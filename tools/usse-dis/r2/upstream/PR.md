## PR description (paste into GitHub)

> **##arch: PowerVR SGX Series-5 USSE disassembler**
>
> Adds a clean-room `usse` architecture plugin for the PowerVR SGX USSE ISA (Series-5 / SGX5xx) —
> fixed 8-byte little-endian instructions. Decodes `mov`/`limm`, integer ALU
> (`and`/`or`/`xor`/shifts, `imae`/`ima16`), loads/stores (`ldad`/`stad` with addressing modes),
> control (`idf`/`wdf`/`lock`/`ci`/`cfi`/`smlsi`/`nop`/`lapc`/`emitpds`), and `ba`/`br` branches
> (+`.savelink`) with `op->type` + jump/call/fail so analysis and graphs work. `arch usse`,
> `bits 32`, little-endian.
>
> Validated against the SGX545 microkernel and the SGX540 ukernel/TA/3D/SPM corpus: **99.9% of
> the microkernel decodes identically to Imagination's own `ref_usse_disasm`**. The decoder was written
> independently and checked against `ref_usse_disasm` used purely as a black-box oracle — **no vendor
> source is copied or included**.
>
> Usage: `r2 -a usse -b 32 <blob>` → `pd`, `aa`, `agf`.

## Local verification done

- **acr (full build on macOS):** `usse` compiles, registers as a built-in static arch plugin,
  and r2 disassembles the SGX545 microkernel correctly (jump arrows render).
- **meson:** `meson setup` accepts the plugin and both TUs compile; the full link hit a
  pre-existing, unrelated `libr_syscall`/gperf issue in r2-master on this macOS (not touched by
  this change) — r2's Linux CI builds the syscall tables fine.
- Decoder regression (`../oracle_check.py`): 0 wrong vs `ref_usse_disasm` across 17k+ instructions.
